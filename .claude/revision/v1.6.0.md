# v1.6.0 (versionCode 38) — Tích hợp Follow4Follow

## Yêu cầu
Dựa trên bộ tài liệu Follow4Follow (`Test.zip`): hoàn thiện luồng đăng nhập, làm nhiệm vụ…; cập nhật tài liệu vào repo; xoá bớt tài liệu không còn dùng.

## What changed
- **Provider mới** `tasks/f4f/`: ký request HMAC-SHA256 (`F4fSigner`), HTTP client không phụ thuộc thư viện (`F4fApiClient` + `UrlConnectionTransport`), `Follow4FollowProvider` (acc → `quick-switch` → job → `mark-start` → complete/skip; hàng đợi job; hết lượt ngày; 401/429), `F4fAuthManager` (login/refresh/logout + `StateFlow`, token qua `StringEncryptor`).
- **Giao diện đăng nhập:** `F4fLoginDialog` + `F4fAccountCard` (Cài đặt → Nhiệm vụ); hàng "Nhiệm vụ kiếm tiền" ở tab Dịch vụ mở hộp thoại nếu chưa đăng nhập và hiện tài khoản/số dư khi đã đăng nhập; nút Bắt đầu ở Dashboard yêu cầu đã đăng nhập khi chọn chế độ nhiệm vụ.
- **`TaskProvider`:** `nextJob(account, kinds)`, `onJobOpening()`, `noJobReason()`, `TaskAccount.providerData`; `TaskProviders.current(context)` trả provider thật.
- **`AutomationEngine` (task mode):** chỉ hỏi loại job đã cấu hình; gọi `onJobOpening` trước khi mở link; 429 ở `complete` → chờ rồi báo lại 1 lần; lỗi nghiệp vụ → `skip`; log lý do khi không có job.
- `AppConstants.TASKS_ENABLED = true`; `StringEncryptor.F4F_SIGN_KEY`.
- **Tài liệu:** `context/Follow4FollowAPI_Documentation.md` + `context/follow4follow/` (`API_reference_v2.txt`, `f4f.py`); ADR-0008; cập nhật README, CLAUDE.md, `context/*`, `tasks/*`.
- **Dọn tài liệu cũ:** xoá `GolikeAPI_Documentation.md`, thư mục `revisions/` (42 nhật ký v1.0–v1.1 + docs-sync 1.3.3), `revision/v1.2.0–v1.2.3` (giữ 10 bản theo `CLAUDE.md`), `QA-013` (checklist cho `FeatureFlags` đã xoá), skill `play-billing-upgrade` + `migrate-xml-to-compose` (dự án không có Play Billing / layout XML), mục nợ kỹ thuật Flutter/Golike đã hết hiệu lực, ràng buộc build Flutter trong `constraints.md`, phần lưu trữ session 14 trong `current_focus.md`.

## Why it changed
Task mode chưa có nhà cung cấp từ v1.4.0; bộ tài liệu F4F mới đủ để làm trọn luồng kiếm coin. Tài liệu cũ nói về Golike/Flutter/FeatureFlags gây nhiễu.

## Rollback note
Đặt `AppConstants.TASKS_ENABLED = false` để ẩn toàn bộ tính năng mà không gỡ code. Gỡ hẳn: `git revert` commit này (provider là package riêng, engine chỉ đổi trong khối task mode). File tài liệu đã xoá khôi phục bằng `git checkout <commit-trước> -- .claude`.

## Risks / follow-ups
- Toàn dự án chưa compile trong sandbox → **CI là xác nhận cuối** (xem `current_focus.md`).
- Chưa test với server thật: schema dựa trên `API_reference_v2.txt` + response mẫu field-tested của `f4f.py`.
- Khoá ký là hằng số công khai trong bundle web — site đổi bundle sẽ làm mọi request bị từ chối.
- Token chỉ được che (XOR), chưa dùng Keystore.
- `report-job` chưa nối vào engine; chưa có luồng liên kết acc TikTok trong app.
